# Exact 0.156.1 local attachment

Package candidate 0.4.0 adds the `v0_156_1` facade with an independently retained
310-file stable schema tree generated by the official native 0.156.1 binary.
`protocol/profiles/0.156.1/upstream-manifest.json` records its exact binary,
source tag/commit, file hashes and schema roots. No earlier qualification is
relabeled. The 0.147.0 and 0.162.1 selected surfaces and schemas remain unchanged.

Use the facade matching the selected executable:

```python
from codex_app_server_client import v0_156_1 as codex

binary = codex.resolve_codex_binary("/absolute/path/to/codex")
compatibility = codex.inspect_compatibility(binary)
client = await codex.AppServerClient.connect(
    codex.LocalWebSocketTransport("/absolute/path/to/control.sock"), compatibility
)
session = await client.initialize(codex.ClientIdentity("consumer", "1"))
page = await session.list_turns(codex.ThreadTurnsListParams(
    threadId="exact-thread", limit=20, itemsView="full"
), timeout=5)
await client.close()
```

The caller must bind the socket to its intended daemon and retain that authority.
Executable schema inspection cannot authenticate the process behind an arbitrary
socket. Initialization schema-validates and exposes returned metadata through the
shared session owner; the caller verifies the intended daemon and version. This local transport has no TCP URL, proxy, credential discovery,
listener, daemon start/stop, process ownership, or retry policy.

The handshake has a five-second deadline and 16 KiB header bound. Only an exact
valid WebSocket upgrade is accepted; compression, subprotocols, duplicate headers,
masked server frames, binary frames, invalid continuation/UTF-8/control frames,
and nonminimal frame lengths fail closed. Text messages are limited to 8 MiB,
also subject to the caller's smaller RPC bound, with at most 1,024 frames per
message. Client frames are masked. Ping/pong is handled inside that bound.
Cancellation after partial framing closes the generation rather than resuming
at an uncertain frame boundary. Disconnect cleanup proves the client socket
descriptor closed even when asyncio retains a peer reset/broken-pipe exception;
unproven cleanup still blocks replacement. Done-task ownership callbacks are
allowed to finish before either RPC or callback quiescence is declared.

`list_turns` requires an explicit 1–100 page limit and explicit `itemsView`:
`full`, `summary`, or `notLoaded`. Consumers must follow `nextCursor` themselves
and preserve the returned item coverage. A summary or partial page is not full
activity evidence. The new request and transport are recognized enum values,
but only this exact profile admits them; legacy profiles reject before I/O.

The native smoke owns a disposable credential-free home and daemon, initializes,
lists threads, starts one thread without a turn, observes the native invalid-request
response to its bounded full-history request, closes its client and verifies the
daemon survives that close, then
terminates/reaps only its own daemon. It starts no model turn and provides no
downstream customer-connection or semantic monitoring evidence.

Historical full-repository package/composition qualification records remain
unchanged. This bounded successor qualifies this distribution alone, and does
not claim a new aggregate package-set qualification, publication or release.

The [exact upstream processor](https://github.com/openai/codex/blob/b412ff32c417f855c2b2d1581b77058eed87c84b/codex-rs/app-server/src/request_processors/thread_processor.rs)
rejects history reads before the first user message materializes the thread.
The smoke records error code -32600, not a successful native turn page. Successful
pagination responses are covered by neutral peer tests; live-run evidence belongs
to each consumer qualification.
